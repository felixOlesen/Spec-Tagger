# Prompt Creation

story~creating_a_successful_prompt_object~1
Prompts are created through constructing different sentences into one large prompt prose that can then be sent to an LLM. This prompt prose is constructed form tag information, including its items, test results and coverage, and associated problem type. On top of this, there are a series of problem statements and solution statements that get added to point the LLM in the right direction. One prompt can contain multiple problem statements, should there be multiple problems that occur. Then it is compiled with relevant git information to form a useful prompt for an LLM.
